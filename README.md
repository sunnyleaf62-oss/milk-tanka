# ミルク単価くらべ：楽天価格の自動取得

楽天市場の全ショップから粉ミルクの価格を集め、100mlあたりの単価が安い順に `data.json` へ書き出します。

## ファイル
- `rakuten_fetch.py`：価格を取ってくる本体
- `products.json`：比較する商品の一覧（ここに追加すれば商品が増えます）
- `.github/workflows/update.yml`：GitHubで毎朝自動実行する設定

## 必要な4つの値
| 名前 | 中身 |
|---|---|
| RAKUTEN_APP_ID | Rakuten Developersのアプリケーション ID |
| RAKUTEN_ACCESS_KEY | 同じ画面のアクセスキー（人に見せない） |
| RAKUTEN_AFFILIATE_ID | 同じ画面のアフィリエイトID |
| RAKUTEN_REFERER | 許可されたウェブサイトに入れたURL（例 `https://www.threads.com/`） |

GitHubで使う場合は、リポジトリの Settings → Secrets and variables → Actions に4つとも登録します。コードやファイルにキーを直接書かないでください。

## 集め方のルール
- 商品名に `must` の言葉が全部入っていて、`ng` の言葉が入っていない出品だけを使います
- 「800g×2缶」「24本入」などを読み取って、作れるミルクの量を計算します
- 送料別の出品は、送料の目安（800円）を足した「送料込み価格」で比べます（楽天APIは送料の金額を返さないため）
- 1商品につき最大90件を確認し、同じショップの重複は一番安いものだけ残します
- 個数の読み違いで極端に安く見えるもの（中央値の6割未満）は除外します

## 商品の追加例
```json
{
  "id": "hohoemi_stick",
  "brand": "明治",
  "name": "ほほえみ らくらくキューブ 小箱",
  "form": "キューブ",
  "keyword": "明治 ほほえみ らくらくキューブ 432g",
  "must": ["ほほえみ", "キューブ", "432"],
  "ng": ["中古"],
  "unit_g": 432,
  "g_per_100ml": 13.5,
  "min_price": 1000
}
```
`g_per_100ml` は缶に書いてある調乳の目安から、100ml作るのに必要なグラム数を入れてください。
